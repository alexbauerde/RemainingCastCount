# Changelog

## 1.0.0 (2026-10-11)

- First release on GitHub.
- Shows on each action button how many times you can still cast its spell with your current
  mana, with warning colors for 0 and 1–2 casts.
- Works with the Blizzard action bars and LibActionButton bars (Bartender, ElvUI and others).
- Settings page (/rcc): turn single spells or spell ranks off, font size and color, drag the
  number to where it should sit on the button, minimap button.
- Threshold per spell: in the spell list, enter a number and the count only shows on the
  button once it is that number or lower. With "Show all spell ranks" each rank can have
  its own threshold; ranks without one use the spell's.
- English and German.
